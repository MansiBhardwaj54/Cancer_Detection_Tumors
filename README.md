Tumor Classification: Malignant vs. Benign
Overview
This project leverages machine learning to classify tumors as malignant or benign using the Breast Cancer Wisconsin (Diagnostic) Dataset. The objective is to develop a neural network model that aids in early cancer detection, helping healthcare professionals make informed decisions.

By analyzing tumor-related features derived from fine-needle aspiration (FNA) of breast masses, this project provides a scalable and efficient solution for initial assessments in cancer diagnosis.

Key Features
1. Binary classification of tumors into malignant or benign.
2. Uses a fully connected neural network implemented in TensorFlow/Keras
